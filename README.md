# running-route-planner
A graduation project focused on generating personalized running and walking routes in the Fatih district of Istanbul.

## Team Members
- Elif Şensoy
- Zeynep Özeren
- Azra Gündoğan

## Project Scope
- Static geospatial dataset construction for Fatih
- Route generation using graph-based methods
- Baseline and PSP-based routing experiments
- Basic web interface prototype.

## Repository Structure
- `data/`: raw and processed datasets
- `src/`: source code
- `docs/`: project notes and design decisions
- `reports/`: course reports
- `tests/`: test code
